# 未来の一片

朝に未来の場面を一つ読み、日本語のキーボードで書き写すiPhone・iPadアプリです。iOS／iPadOS 26以降に対応する設計です。本文29本を収録し、１日ごとに固有の場面画を表示します。

- アラーム画面の＋で時刻と繰り返しを選びます。１回、毎日、平日、曜日指定があり、異なる時刻を複数登録できます。初期時刻は5:30です。
- iPhoneのアラームに出る「今日の一片を開く」を押すと、音を止めて場面を開きます。「停止」だけを押した場合は、1分後にもう一度鳴る設計です。
- アプリを開いてから1分経つまでに操作がない場合や、途中でアプリを離れた場合にも再アラームを設定します。「今日は読むだけにする」でも朝のアラームを終了できます。
- 日本語変換を確定した文字と句読点を照合します。一致したら「未来へ送る」を押し、絵葉書に残せます。絵葉書の「もう一度書く」から再体験しても、同じ絵葉書は増えません。
- 元のHTMLの絵葉書はそのブラウザに保存されています。アプリ版の絵葉書はアプリ内に新しく保存されます。
- ショートカットの「URLを開く」で `mirai-hitohira://today?text=...` を使うと、URLエンコードした文章を今日の一片として表示できます。

## iPhoneからIPAを入手する

1. GitHubの **Actions → Build iPhone IPA → Run workflow** で、`main` を選びます。実行前にアカウントの無料枠と超過課金の停止設定を確認してください。
2. ビルドが成功したら、その実行の **Artifacts → MiraiNoHitohira** をダウンロードします。成果物の保存期間は3日です。
3. iPhoneの「ファイル」でZIPを展開し、SideStoreの **My Apps → ＋** から `MiraiNoHitohira.ipa` を選んでインストールします。

## 実機での確認

アプリの「20秒後にテスト」を選び、画面をロックします。「今日の一片を開く」で同じ場面を表示できること、変換途中で照合しないこと、入力中断後の再鳴動、完了と「今日は読むだけにする」で再鳴動が終了することを確認します。
